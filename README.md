有料会員向けの抽選管理ツール開発リポジトリです。

## 現在の共有プレビュー

`preview-v2.5.html`

共有URL：
`https://tomzeroichi.github.io/chusenkanri-db/`

現在確認できる内容：

- POKÉMON / ONE PIECE / DRAGON BALL / OTHER・TOY の色分け
- 薄い蛍光系のカード背景 + はっきりした縁取り
- 未応募は固定サイズの「未」バッジで表示
- 上部集計はスマホでも4つ横並びのコンパクト表示
- 締切日・時刻を大きく表示
- 一覧は折りたたみ式
- 2カテゴリ・3カテゴリを同一抽選に設定可能
- 複数カテゴリ時は左側の縁を2色・3色に分割表示
- アプリから応募する抽選にも対応
- アプリ会員限定などの会員条件表示
- 店舗一覧 / 詳細 / 会員登録 / 応募フォームをリンク種別として表示
- 会員ごとのステータス管理イメージ

## 本番化の方針

運営共通データと会員個別データを分離します。

- 運営：抽選情報、締切、応募方法、各種URL、商品マスタを管理
- 会員：未応募 / 結果待ち / 当選 / 購入済み / 受取済みを個別管理
- 認証・DB：Supabase Auth + Postgres + RLS を予定
- 運営が抽選内容を更新すると全会員へ共通反映
- 個人の進捗やメモは他ユーザーに影響しない設計
